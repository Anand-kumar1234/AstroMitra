# 🧠 Quiz App

An interactive and user-friendly Quiz Application built to help users test their knowledge through multiple-choice questions. The app provides instant feedback, score tracking, and an engaging learning experience.

## 🚀 Features

- 📚 Multiple Choice Questions
- ⏱️ Timer-Based Quiz
- 🎯 Instant Score Calculation
- 📊 Result Summary
- 📱 Responsive Design
- 🌙 Modern User Interface
- 🔄 Restart Quiz Option

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Deployment
- Vercel
