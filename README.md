# 🔮 AstroMitra

AstroMitra is a modern astrology and horoscope platform designed to provide users with daily horoscope updates, zodiac insights, astrological guidance, and celestial knowledge in a simple and user-friendly interface.

## ✨ Features

- 🌟 Daily Horoscope Predictions
- ♈ Zodiac Sign Information
- 🌙 Astrology-Based Insights
- 📅 Personalized Horoscope Experience
- 🔍 Easy Navigation and Search
- 📱 Fully Responsive Design
- ⚡ Fast and Modern User Interface

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Anand-kumar1234/AstroMitra.git
```

### 2. Navigate to Project Directory

```bash
cd AstroMitra
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
